Featured project

Coeus AI

Coeus AI is a native C++ project-aware AI desktop workspace. It was built to explore how an assistant can work against a loaded local software project: retrieving source context, answering codebase-aware questions, coordinating workflow-style operations, and exposing telemetry for debugging and evaluation.

View Coeus Repository Download Demo Release Coeus Docs Site Evaluation Reports

What it demonstrates

Native desktop engineering

Custom C++20 desktop application using Skia, SDL2, and OpenGL rather than a browser-only chat interface.

Project-aware AI runtime

Runtime concepts for loaded project state, file inventory, retrieval, context assembly, source-grounded answers, and follow-up continuity.

Evaluation discipline

Private headless test harness used to generate portfolio-facing reports for repository grounding, negative grounding, routing discipline, and artifact suppression.

Technical highlights

  • Native C++20 desktop application.
  • Custom Skia/SDL2/OpenGL GUI.
  • Local project inventory and codebase retrieval.
  • Source-grounded repository QA and semantic comparison.
  • Workflow/task orchestration and tool-style runtime operations.
  • Structured telemetry and diagnostic surfaces.
  • Private headless evaluation harness with generated HTML/SVG reports.

Public release scope

The public Coeus repository is a portfolio/demo package. It is intended to show the compiled GUI demo, documentation, architecture, evaluation reports, and engineering story without exposing private implementation source.

The full source code, private prompts, proprietary runtime internals, private traces, and private headless runner are not included.
