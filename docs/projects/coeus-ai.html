Coeus AI

Coeus AI is a native C++ project-aware AI desktop workspace for working with software projects. It combines a custom Skia/SDL2 graphical interface, local project context, retrieval over codebases, workflow-style runtime operations, structured telemetry, and a private headless evaluation harness used to test repository-grounded behaviour.

What this project is

Coeus AI was built around the idea that an assistant should understand the currently loaded project, not just answer as a generic chatbot. The app is designed to load or work against a local software project, inspect project context, retrieve relevant source files, answer repository-aware engineering questions, compare files semantically, and preserve context across follow-up turns.

The public Coeus repository is a portfolio/demo package. The full source code remains private, but the public package provides documentation, architecture notes, benchmark reports, release material, and a compiled Windows GUI demo distributed through GitHub Releases.

Why it matters

A common failure mode in AI coding tools is that they sound confident while losing repository context, hallucinating unsupported features, or routing normal codebase questions into the wrong workflow. Coeus AI explores a more structured approach to project-aware assistance.

  • Separate local project inventory from source evidence.
  • Assemble answer context from actual project files.
  • Distinguish semantic repository questions from patch/diff requests.
  • Retain repository context across follow-up turns.
  • Identify absent features without hallucinating implementation.
  • Suppress internal trace/vector/project-storage artifacts from user-facing answers.

Technical highlights

Native desktop app

C++20 desktop application with custom Skia rendering and SDL2/OpenGL windowing rather than a browser-only chat interface.

Project-aware runtime

Runtime concepts for active project state, file inventory, source evidence, retrieval, context assembly, answer routing, and continuity.

Workflow and tools

Tool-style runtime operations, task/workflow orchestration, command handling, planning/apply-style flows, and runtime state tracking.

Telemetry and evaluation

Structured telemetry and a private headless evaluation harness used to generate portfolio-facing HTML/SVG reports.

Public / private boundary

Coeus AI is currently presented as a portfolio/demo release. The public repository includes documentation, generated evaluation reports, release material, and public-facing project notes. It does not include the full private source code, private prompts, proprietary runtime internals, private traces, private provider configuration, or the private headless runner.
